# LeetCode 3622 - Check Divisibility by Digit Sum and Product

## Problem Statement

You are given a positive integer `n`.

Calculate:

* The **digit sum** of `n`.
* The **digit product** of `n`.

Return `true` if `n` is divisible by the **sum of these two values**. Otherwise, return `false`.

In other words:

```text
n % (digitSum + digitProduct) == 0
```

---

## Examples

### Example 1

```text
Input:
n = 99

Digit Sum:
9 + 9 = 18

Digit Product:
9 × 9 = 81

Total:
18 + 81 = 99

99 % 99 = 0

Output:
true
```

### Example 2

```text
Input:
n = 123

Digit Sum:
1 + 2 + 3 = 6

Digit Product:
1 × 2 × 3 = 6

Total:
6 + 6 = 12

123 % 12 != 0

Output:
false
```

---

## Approach

We can solve this problem by extracting each digit of `n`.

For every digit:

1. Add it to `sum`.
2. Multiply it with `product`.
3. Remove the last digit using integer division by `10`.

After processing all digits:

```text
sum + product
```

is the value by which we need to check divisibility.

Finally:

```text
n % (sum + product) == 0
```

If this is true, return `true`; otherwise, return `false`.

---

## Algorithm

1. Initialize:

   ```text
   sum = 0
   product = 1
   ```
2. While `n > 0`:

   * Extract the last digit using `n % 10`.
   * Add the digit to `sum`.
   * Multiply the digit with `product`.
   * Remove the last digit using `n /= 10`.
3. Check:

   ```text
   originalNumber % (sum + product)
   ```
4. Return whether the remainder is `0`.

## C++ Solution

```cpp
class Solution {
public:
    bool checkDivisibility(int n) {
        int original = n;
        int sum = 0;
        int product = 1;

        while(n > 0) {
            int digit = n % 10;

            sum += digit;
            product *= digit;

            n /= 10;
        }

        return original % (sum + product) == 0;
    }
};
```

Let `d` be the number of digits in `n`.

### Time Complexity


Only a constant number of variables are used.
