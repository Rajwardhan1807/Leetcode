# 3090. Maximum Length Substring With Two Occurrences

**Difficulty:** Easy
**Topics:** String, Sliding Window, Hash Table

## Problem

Given a string `s`, return the **maximum length of a substring** such that it contains **at most two occurrences of each character**.

### Example

```text
Input:
s = "bcbbbcba"

Output:
4
```

## Approach

We can solve this problem efficiently using the **Sliding Window** technique.

Maintain a window between `left` and `right`:

1. Expand the window by moving `right`.
2. Store the frequency of each character.
3. If the current character appears more than `2` times, shrink the window by moving `left`.
4. Continue until the window becomes valid.
5. Update the maximum length.

### Why Sliding Window?

When a character appears more than twice, we don't need to start over. We only move `left` forward until the invalid character's frequency becomes valid again.

This allows us to process each character at most a few times.

## C++ Solution

```cpp
class Solution {
public:
    int maximumLengthSubstring(string s) {
        vector<int> freq(26, 0);

        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.size(); right++) {
            freq[s[right] - 'a']++;

            // Shrink the window if the current
            // character occurs more than twice.
            while (freq[s[right] - 'a'] > 2) {
                freq[s[left] - 'a']--;
                left++;
            }

            maxLen = max(maxLen, right - left + 1);
        }

        return maxLen;
    }
};
```

## Complexity

| Complexity | Value  |
| ---------- | ------ |
| Time       | `O(n)` |
| Space      | `O(1)` |

The space complexity is `O(1)` because the frequency array contains only 26 characters.

## Key Concept

> **Sliding Window + Frequency Array**

The important condition is:

```text
frequency[character] <= 2
```

Whenever this condition is violated, shrink the window until it becomes valid again.
