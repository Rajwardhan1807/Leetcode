# LeetCode 3014 - Minimum Number of Pushes to Type Word I

## Problem Statement

You are given a string `word` containing distinct lowercase English letters.

A telephone keypad has keys mapped with collections of letters. To type a letter, we need to press its assigned key a certain number of times based on its position on that key.

For example:

```text
Key 2 → ["a", "b", "c"]

a → 1 push
b → 2 pushes
c → 3 pushes
```

You are allowed to remap keys `2` to `9` with any distinct collections of letters.

Each letter must be assigned to exactly one key.

Return the minimum number of key presses needed to type `word` after optimally remapping the keypad.

# Approach

Since all letters in `word` are distinct, the goal is to assign every character the smallest possible push count.

There are **8 available keys** (`2` to `9`).

To minimize pushes:

* The first 8 letters can be assigned to different keys and require only **1 push**.
* The next 8 letters require **2 pushes**.
* The next 8 letters require **3 pushes**.
* The last 2 letters require **4 pushes**.

This follows a greedy strategy:

* Fill available one-push positions first.
* Then two-push positions.
* Continue increasing the push count.

---

# Algorithm

1. Count the number of letters in `word`.
2. Assign push counts based on their positions:

   * Positions `0-7` → 1 push
   * Positions `8-15` → 2 pushes
   * Positions `16-23` → 3 pushes
   * Positions `24-25` → 4 pushes
3. Add all required pushes and return the result.

# C++ Solution

```cpp
class Solution {
public:
    int minimumPushes(string word) {
        int ans = 0;

        for(int i = 0; i < word.length(); i++) {
            ans += (i / 8) + 1;
        }

        return ans;
    }
};
```
