# LeetCode 3345 - Smallest Divisible Digit Product I

## Problem Statement

You are given two integers `n` and `t`.

Return the **smallest** integer greater than or equal to `n` such that the **product of its digits** is divisible by `t`.

---

## Examples

### Example 1

```text
Input:
n = 10
t = 2

Output:
10
```

Explanation:

```text
Product of digits = 1 × 0 = 0

0 is divisible by 2.
```

---

### Example 2

```text
Input:
n = 15
t = 3

Output:
16
```

Explanation:

```text
15 → 1 × 5 = 5 (Not divisible by 3)

16 → 1 × 6 = 6 (Divisible by 3)
```

---

## Approach

Since the constraints are small, a brute-force approach is sufficient.

Starting from `n`, repeatedly:

1. Calculate the product of its digits.
2. Check whether the product is divisible by `t`.
3. If it is divisible, return the current number.
4. Otherwise, increment the number and continue searching.

Because numbers are checked in increasing order, the first valid number found is guaranteed to be the smallest.

---

## Algorithm

1. Start with the given number `n`.
2. Compute the product of all its digits.
3. If the product is divisible by `t`, return `n`.
4. Otherwise, increment `n` and repeat.

## C++ Solution

```cpp
class Solution {
public:
    int smallestNumber(int n, int t) {
        while(1) {
            int prod = 1;

            // Find digit and multiply
            int copy = n;

            while(copy != 0) {
                int rightMostDig = copy % 10;
                prod = prod * rightMostDig;
                copy = copy / 10;
            }

            if(prod % t == 0)
                return n;

            n++;
        }

        return 1;
    }
};
```

## Complexity Analysis

Let:

* `d` = number of digits in the current number.
* `k` = number of integers checked before finding the answer.

### Time Complexity

```text
O(k × d)
```

Each number requires traversing all of its digits to compute the product.

### Space Complexity

```text
O(1)
```

Only a few integer variables are used.
