# LeetCode 3518 - Smallest Palindromic Rearrangement II

## Problem Statement

You are given a palindromic string `s` and an integer `k`.

Return the **k-th lexicographically smallest palindromic permutation** of `s`. If there are fewer than `k` distinct palindromic permutations, return an empty string.

Different rearrangements that produce the same palindrome are counted only once.

---

## Examples

### Example 1

```text
Input:
s = "abba"
k = 2

Distinct Palindromes:
1. "abba"
2. "baab"

Output:
"baab"
```

### Example 2

```text
Input:
s = "aa"
k = 1

Output:
"aa"
```

### Example 3

```text
Input:
s = "aaa"
k = 2

Output:
""
```

Only one distinct palindromic rearrangement exists.

---

# Approach

A palindrome is completely determined by its **first half**, since the second half is simply its mirror image.

Instead of generating every palindrome, we construct the answer one character at a time.

---

## Key Observations

* Every character appears an even number of times except possibly one middle character.
* Only half of each character's occurrences need to be arranged.
* The second half is obtained by reversing the first half.
* At every position, characters are tried in lexicographical order.

For every candidate character:

1. Place it in the current position.
2. Count how many valid first halves can be formed using the remaining characters.
3. If this count is smaller than `k`, skip all those permutations.
4. Otherwise, keep the character and continue constructing the answer.

This allows us to directly build the **k-th palindrome** without enumerating all possibilities.

---

# Algorithm

1. Count the frequency of every character.
2. Store half of each frequency.
3. Identify the middle character (if any).
4. Build the first half greedily:

   * Try characters from `'a'` to `'z'`.
   * Count remaining permutations.
   * Skip or choose accordingly.
5. Reverse the first half.
6. Return:

```text
firstHalf + middle + reverse(firstHalf)
```

# Complexity Analysis

Let

* `n` = length of the string
* `σ = 26` (alphabet size)

### Time Complexity

```text
O(n × σ)
```

Each position of the first half tries at most 26 characters, while combinatorial counting determines how many permutations remain.

### Space Complexity

```text
O(σ)
```

Only the frequency array and recursion/state variables are maintained.
