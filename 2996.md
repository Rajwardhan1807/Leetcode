# LeetCode 2996 - Smallest Missing Integer Greater Than Sequential Prefix Sum

## Problem Statement

You are given a **0-indexed** array of integers `nums`.

A prefix `nums[0..i]` is **sequential** if:

```text
nums[j] = nums[j - 1] + 1
```

for every `1 <= j <= i`.

The prefix containing only `nums[0]` is always considered sequential.

Return the **smallest integer `x`** that:

* `x` is greater than or equal to the sum of the longest sequential prefix.
* `x` is not present in `nums`.

---

```text
Sum:

Output:
6
```

# Approach

The problem can be solved in two steps.

### Step 1: Find the Longest Sequential Prefix

Start with `nums[0]` as the initial sum.

Traverse the array and check whether the current element is exactly one greater than the previous element.

```text
nums[i] == nums[i - 1] + 1
```

If the condition is true, add the current element to the sum.

If the condition fails, the sequential prefix ends.

---

### Step 2: Find the Smallest Missing Integer

Once the sum is calculated, start checking from `sum`.

If `sum` exists in the array, increment it and check again.

Continue until a number that does not exist in the array is found.

Since we use `find()` directly on the vector, no additional data structure is required.

---

# Algorithm

1. Initialize `sum = nums[0]`.
2. Traverse the array from index `1`.
3. If `nums[i] == nums[i-1] + 1`, add `nums[i]` to `sum`.
4. Stop when the sequential pattern breaks.
5. Check whether `sum` exists in `nums`.
6. If it exists, increment `sum`.
7. Repeat until `sum` is missing.
8. Return `sum`.

# C++ Solution

```cpp
class Solution {
public:
    int missingInteger(vector<int>& nums) {
        int sum = nums[0];

        // Find the longest sequential prefix
        for(int i = 1; i < nums.size(); i++) {
            if(nums[i] == nums[i - 1] + 1)
                sum += nums[i];
            else
                break;
        }

        // Find the smallest missing integer
        while(find(nums.begin(), nums.end(), sum) != nums.end())
            sum++;

        return sum;
    }
};
```

# Complexity Analysis

Let `n` be the size of `nums`.

### Time Complexity

```text
O(n²)
```

Finding the sequential prefix takes `O(n)`.

For every missing-number check, `find()` takes `O(n)` in the worst case.

In the worst case, the search may be repeated multiple times, resulting in `O(n²)`.

### Space Complexity

```text
O(1)
```

No additional data structure is used.
